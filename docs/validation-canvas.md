# 画布约束标记

日期：2026-11-17；版本：v0.6.0。

默认显示当前所选对象相关的约束。功能区“画布标记”提供“仅所选对象”“显示全部”“隐藏标记”三个互斥选项。每条可见关系显示 Office 图标、约束名称和已有固定参数，并用细引导线连接成员。蓝色表示有效关系，灰色表示停用，红色表示未满足或成员缺失。

标记使用现有 `LayeredWindowSurface` 的原生逐像素透明窗口，不抢焦点、不捕获鼠标或键盘，全部鼠标命中穿透。修改、停用和删除仍通过约束窗格进行。徽章避让对象框与缩放点；可用空间不足时跳过该徽章，完整关系仍可在窗格查看。

只读显示快照把对象 UI key 和几何 GUID 分开处理。闲时刷新关系与选择；拖动时直接使用拖动控制器已经写回并核对的不可变几何快照。投影重采样 PowerPoint 的 `PointsToScreenPixelsX/Y`，标记尺寸只按显示 DPI 缩放。普通视图、幻灯片 pane、前台窗口和同线程同进程的 `mdiClass` 画布均需满足；切窗、换页、失焦、最小化、文字编辑或轮盘打开时隐藏或重建。

## 已完成验证

- 完整构建与 254 项检查通过，其中 20 项新增画布检查覆盖关系筛选、UI key/GUID 区分、多成员、投影和 DPI、离屏裁剪、碰撞避让、参数、状态、真实中文字体测量与透明像素。一次构建在窗格 29 条断言全部通过后，于进程退出阶段触发 `UIAutomationCore.dll` 的异常；事件日志确认故障模块，单独窗格检查及随后完整构建均正常退出，未添加绕过或自动重试。
- 新 PowerPoint 进程已载入 v0.6.0。独立测试文稿包含矩形 A、文本框 B、椭圆 C，以及顶端对齐、同宽、水平等间距和固定宽度四条关系。
- 程序化选择 A 显示三条相关关系，C 显示两条，取消选择隐藏；“全部”显示四条，“隐藏”不显示。65%、100%、130% 缩放后的投影与 Office 坐标接口一致。
- 程序化进入 B 的文字选择状态时隐藏，退出后恢复。显示开关、缩放和选择没有增加形状或改变文稿 Saved 状态。
