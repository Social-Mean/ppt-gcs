# 画布约束标记

## 画布标记操作

单击标记会选中参与对象并高亮标记和对应引导线。已打开的约束窗格会选中该关系。双击带参数的标记会在窗格显示当前值和单位，可按 Enter 保存。右键标记可以启用、停用或删除对应关系。数值修改、启停及删除复用窗格的命令和原生撤销。

透明窗口继续穿透。PowerPoint 所在线程的鼠标路由处理落在标记中的普通左键和右键点击，超出拖动阈值会取消。排版会为未参与约束的对象和缩放点留出空间。提交前核对当前窗口、幻灯片和关系。右键菜单由 PowerPoint 窗口承载，通过 `TrackPopupMenuEx` 取得所选动作，菜单打开时方向键由菜单处理。 [Microsoft Win32 文档](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-trackpopupmenuex)

## v0.6.0 显示验证

日期：2026-11-17；版本：v0.6.0。

默认显示当前所选对象相关的约束。功能区“画布标记”提供“仅所选对象”“显示全部”“隐藏标记”三个互斥选项。每条可见关系显示 Office 图标、约束名称和已有固定参数，并用细引导线连接成员。蓝色表示有效关系，灰色表示停用，红色表示未满足或成员缺失。

初版使用 `LayeredWindowSurface` 建立原生逐像素透明窗口，鼠标命中穿透。标记避让对象框与缩放点。可用空间不足时跳过标记，完整关系仍显示在窗格中。

只读显示快照把对象 UI key 和几何 GUID 分开处理。闲时刷新关系与选择；拖动时直接使用拖动控制器已经写回并核对的不可变几何快照。投影重采样 PowerPoint 的 `PointsToScreenPixelsX/Y`，标记尺寸只按显示 DPI 缩放。普通视图、幻灯片 pane、前台窗口和同线程同进程的 `mdiClass` 画布均需满足；切窗、换页、失焦、最小化、文字编辑或轮盘打开时隐藏或重建。
