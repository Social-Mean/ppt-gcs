## 可重复运行的检查

在 64 位 Windows PowerShell 5.1 中构建插件，并在 PowerPoint 重启加载该构建后执行：

```powershell
powershell.exe -NoProfile -STA -File scripts/TestEditingEntries.ps1
```

回放检查包含：

- 所选受约束对象与自由对象、零宽线条共同平移；从两端驱动与多个驱动同时移动。
- 方向键连续微调、Ctrl 精细步长、网格步长，以及组内成员微调。
- 真实子对象移动、拉伸和同组多选移动；关联对象跟随；精确子成员选择保留。
- 每组有变化的操作均在返回后独立执行一次原生 Undo、一次 Redo，再读取完整几何和元数据比较。共十二组含重开后的再次回放。
- 固定位置的顶层多选原子拒绝；固定根组顶边外移在写入前拒绝，用之前的自由对象编辑作为 sentinel，确认一次 Undo 没有被空操作占用。
- 保存、关闭、重开后完整约束 XML、标签、所有对象与组内成员的几何保持一致，再次回放仍联动。选择状态只记录，不假定会持久化。

这些是公开插件 API 的程序回放，不是物理鼠标、键盘或原生数值控件的交互证据。

## 已取得的原生交互证据

正式插件的 Ribbon 宽度 Enter 输入、高度直接 Tab 输入，已由用户实际操作，并验证双对象同步及一步原生 Undo/Redo。其余物理输入已取得的联动和历史证据见上文逐页检查。

原生基线确认了：多选水平位置逐对象设置绝对坐标；空混合字段的裸数采用系统单位；未修改的舍入显示文本不改变真实尺寸，而重新输入数值会设置 RichEdit 修改标志并提交舍入后的数值。

2026-11-18 又取得真实 Ribbon 宽度上箭头的一次只读采样：字段先从 4.94 厘米变为 5 厘米，在 `WM_NOTIFY/1794` 及随后 `WM_COMMAND/768` 内仍可读到旧的 A 宽度；最终 A 为 141.732284 磅，修改标志一直为 0。记录器停用后的一次原生 Undo/Redo 已核对旧值、最终值和未变化的 B。

独立单次写入原型随后验证：真实 Ribbon 宽度上箭头从 5 到 5.1 厘米时，A/B 各一次 setter 即可保持原生最终宽度；停用记录器、切回画布后，一次原生 Undo 同时恢复 A/B 各自不同的原宽度，一次 Redo 同时恢复目标值，其他几何未变。本机证据：`Sessions/native-spin-apply-once-20261118/native-history.json`。用户随后确认显示同宽，之前的显示差异为观察误判。这仍是单个原型成功案例，未接入生产，不能外推下箭头、鼠标微调、其他字段或冲突取消。

后续标准 subclass 拒绝实验明确失败：真实上箭头处理栈内抑制该来源通知并回填一次旧精确文本后，A 仍从 5.1 变成 5.2 厘米；B 保持 5.1。失焦后的独立读取也确认变化。实验未写形状或修复几何，故不是成功的原子拒绝；详情在本机 `Sessions/native-spin-reject-once-20261118/spin-reject-once.jsonl` 和 `after-focus-loss.json`。全部临时 subclass、hook 和注册均已清理。

原点从左上角切到居中本身会移动对象并产生独立撤销项。水平、垂直位置的居中参考分别增加半个幻灯片宽、高，不减对象半宽、高。读取 COMMAND/NOTIFY 的实验没有找到新原点已选中而对象尚未移动的回调，不能在这些消息之后补写跟随对象并声称共享 Undo。

跨两个根组的子对象原生选择已单独检查：激活幻灯片视图后，两组各自的单成员都可选择；组合成跨根组子成员选择时，PowerPoint 拒绝该请求。插件对此写前拒绝；纯求解器能够处理多个根驱动不代表原生界面能够表达这种选择。自由零宽根组不进入要求正尺寸的求解器。

## 尚未通过的路径

- 组内文字 AutoSize 会改变真实组合边界，同步 WinEvent 里也能读取新边界，但尚未取得一次跟随写入与原生文字 Undo 共同恢复的证据。
- 原点下拉框切换、微调按钮和数值框内上下箭头尚未实现完整联动。
- 左上角参考原点下的水平位置 Enter、垂直位置 Tab，Ribbon 宽高、多选尺寸以及窗口边框提交均有实际操作及原生历史证据。当前为居中时的位置输入、原生面板宽高、原生宽高比锁等组合尚无同等完整的复测。
- 新增上下文不可读时拒绝、只读残差范围、未编辑字段精度保护和初始化清理，已构建并通过程序回放和重开回归；不能用它们代替所有实际输入路径的验收。
- 无写入必要条件预检只处理可证明的固定边界冲突。向内收缩等复杂组内冲突仍可能留下空原生撤销项，没有公开的 PowerPoint 取消撤销事务接口可作为通用保证。

临时原生事件实验保存在本机独立 Sessions 目录，未接入发布代码；它们的只读信号和程序化 COM 编辑结果均不等于原生文字编辑的历史归并证明。
