# 六项改进的实现与验收

用户确认按以下顺序实现，每完成一项独立提交，作者为 Social-Mean。该清单记录实现要求与证据位置，不替代线程中的活动目标状态。各项均须保留文稿内容、原生撤销/重做和保存重开能力。

## 1. 补齐常用几何编辑入口

2026-11-18 用户在原生事务实验之后明确选择“验收已实现入口，提交后继续后五项”。第一项按以下已实现范围验收；后五项保持原定范围。未通过的原生入口不计入本项完成声明，也不接入正式插件。

- 画布方向键及 Ctrl+方向键微调；顶层多选整体移动；组内成员移动、缩放引起的组合外接框变化，驱动相关约束。
- 原生宽度、高度、水平位置、垂直位置的直接数值输入，支持 Enter、Tab/Shift+Tab 和同一 PowerPoint 窗口内点击提交；读取当前左上角或居中参考原点。
- 多选中的无约束对象保持共同移动；组内文字编辑、精确子成员选择正常。
- 一次用户编辑对应一次原生撤销；撤销/重做不会被同步器再次求解，也不会产生多余跟随历史。
- 冲突原子拒绝或恢复实际编辑对象；恢复子成员时不通过缩放整个组合代替。
- 验收包括纯求解检查、真实 PowerPoint 中各入口的双向编辑、冲突、撤销/重做及持久化。输入回放不冒充真实鼠标或面板操作。

本轮不支持原生数值框 ↑/↓ 和增减按钮、切换位置参考原点、文字 AutoSize 引起的组边界变化，以及跨应用切换时的数值提交。文字仍使用 PowerPoint 原生编辑；这些限制在 README 明确列出。数值编辑离开 PowerPoint 前需用已支持方式提交。

## 2. 在画布直接操作约束

- 点击标记高亮/选中关联对象及对应关系。
- 双击宽度、间距等数值进入参数编辑并原子提交。
- 标记右键菜单支持启用、停用、删除；不影响对象的文字、拖动和缩放入口。

## 3. 解释受限编辑和冲突

- 拖动被限制时高亮实际生效的关系。
- 创建或修改发生冲突时指出具体关系和对象，可选择停用关系后重新提交。
- 显示对象位置/尺寸的可编辑方向和固定状态；诊断来自求解条件，不以有无关系代替自由度计算。

## 4. 幻灯片与容器约束

- 支持相对幻灯片边缘、中心和指定容器的对齐、边距/内边距。
- 页面或容器大小变化后关系保持；参数使用明确单位。
- 验证页面尺寸、容器编辑、多成员、冲突和原生历史。

## 5. 完整约束组件复制与共享参数

- 提供明确的“复制对象及内部约束”操作；副本对象、关系编号独立，原件不受影响。
- 支持命名尺寸/间距参数，多个关系可绑定同一参数并统一更新。
- 默认组件副本不意外连接原件；参数复制/共享规则在 UI 中明确。
- 验证跨页复制、编号、关系引用、参数传播、撤销/重做和保存重开。

## 6. 自动提示候选约束

- 编辑时提示可建立的对齐、同宽、等间距等候选关系。
- 用户明确确认后创建；提示自身不修改文稿或历史。
- 避免重复建议，提前过滤不适用或冲突关系；取消、切页和离开编辑区域后清理。

## 提交门槛

每项提交前核对对应源码、测试覆盖、真实应用证据和已知边界；记录准确的完成状态与提交 ID。不能用下一项的工作代替尚未完成的上一项，也不能仅因检查器通过就宣称未验证的原生交互已通过。
