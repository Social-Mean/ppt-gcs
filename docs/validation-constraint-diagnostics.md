# 约束冲突与可编辑方向

选中受约束的对象时，约束窗格显示横向和纵向移动、宽度和高度调整是否可用。尺寸达到相连对象的最小尺寸时，窗格显示“仅可增大”。固定比例会显示“宽高联动”。每条说明对应单独编辑该对象时的求解条件。移动保持当前尺寸，宽高修改对应原生尺寸字段的左上角锚点。组合的外部关系作用于组合外框。

发生冲突时，窗格显示本次提交内容以及经求解确认的冲突关系，包括对象名称和参数。选择要停用的关系，再点“停用所选并重试”。重试沿用原来的约束目标。停用和新建或修改一起写入一次原生撤销。取消时保持文稿内容。文稿切换或约束改变后，重试会先校验原文稿、页面、关系及新参与对象。

拖动被拒绝或角点缩放受到约束投影时，标记用橙色标出限制本次编辑的关系。经其他对象间接施加限制的关系也会临时显示。回到可编辑方向后取消高亮。诊断逐次试算移除候选关系后的编辑，排除无关关系和可删除的冗余关系。一个编辑若有多组独立的限制，提示显示其中一组足以解释当前结果的关系。
