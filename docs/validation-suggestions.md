# 候选约束验证

2026-11-18 在 Windows 桌面 PowerPoint 验证。画布移动、缩放或方向键微移时，插件以受编辑对象为起点检查附近几何，可提示边缘与中心对齐、同宽、同高和两个方向的等间距。接近阈值为 4 磅，一次最多呈现三条候选。原生拖动以 PowerPoint 实际读回的几何为准，原生几何在松手时提交的路径随即刷新提示。

候选可点击的位置与已有标记采用相同的避让和命中规则，并使用带引导线的绿色 **应用…** 标签。预检使用同一求解器。已有或停用的同类关系、等式链已经蕴含的对齐以及与其他关系冲突的尝试都会被过滤。按下标记后在同一标记内松手才确认。确认时按当前文稿和几何复查，然后通过共享命令提交。

## 验收

`Build.ps1` 通过 568 项自动检查。新增检查覆盖多类候选、横纵等距的顺序、过滤已有与冲突关系、只读求解、标签文字与引导线、隐藏模式和离屏过滤。可在项目根目录运行以下命令，生成并打开独立的六页测试文稿。

```powershell
powershell.exe -NoProfile -STA -File .\scripts\NewSuggestionFixture.ps1
```

- 在未约束的 A 上按方向键。看到“应用顶端对齐”时，文稿 XML、对象编号及所有者标记保持原样。一次撤销恢复微移前位置，且没有剩余撤销项。再次微移并实际点击标记后创建顶端对齐，逐次核对原生撤销和重做。
- 拉伸矩形 A 的右侧点后，实际点击“应用同宽”。拖动第三个矩形后，实际点击“应用水平等间距”，核对三对象原生几何与保存的顺序。间距关系通过单步原生撤销和重做。
- 在已有顶端对齐的页面移动 A，确定同类关系未重复出现。另页两个对象顶边接近但分别由固定位置锁定，实际缩放后不出现冲突对齐候选。前后约束 XML 完全一致。
- 分别按 Esc、进入功能区和切页，所有候选清除。实际沿未绑定对象的原生选框拖动后生成候选，从候选按下后拖走没有创建关系。撤销时只撤销原生拖动。
- 保存后在新 PowerPoint 进程打开，完整核对实例编号、关系 XML、文字及几何。再次微移 A，已确认保存的同一对齐关系仍驱动 B。候选未重复出现，一次原生撤销恢复重开时的几何。

实际鼠标与键盘输入通过 Computer Use 发送。Windows 原生窗口采集定位画布，再按可见窗口区域采集包含标记的实际画面。本机状态、截图和验收汇总位于 `%LOCALAPPDATA%/PptGcs/Sessions/suggestions-20261118/0FA397E9-7B38-47EE-960A-BF1A66124C6E/`。`acceptance.json` 汇总检查，`native-border-suggestion.png` 记录真正的提示画面。交互验证覆盖提交几何后的画布状态。
